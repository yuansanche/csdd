# 发布与恢复规范

## 发布前

确认已批准的功能版本、验收结果、最新代码构建、部署环境和实际配置。高风险变更在预发以代表性数据验证。检查迁移顺序、兼容窗口、服务依赖、feature flag 与灰度范围。

## 迁移与恢复

写出备份对象、恢复步骤、预计恢复时间和验证方式。数据不可逆变更优先分阶段迁移；不能只写“回滚镜像”。明确定义回退应用、回退配置、数据恢复或前向修复各自适用条件。关键演练必须记录实际结果。

## 发布后

验证关键流程、错误率、延迟、任务积压、数据一致性和业务指标。设定观察时间、失败触发条件和处理负责人。发现严重异常停止扩大范围，执行既定恢复。

使用 [发布检查表](templates/release-checklist.md)。本包没有生产环境，不声称这些操作已执行。
