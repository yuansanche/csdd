# 编码规范

版本：1.0.0。此文件为本项目选择的规则，不声称完整复现阿里巴巴或 Google 手册。外部参考与冲突见 [external-standards.md](external-standards.md)。

## Java 必须执行的规则

| 编号 | 规则 | 验证方式 / 当前状态 |
|---|---|---|
| JAVA-01 | UTF-8、单一 Google 默认 Java 排版；2 空格、通常 100 列 | 格式器待接入 |
| JAVA-02 | 类、方法、字段按语义命名；无星号 import；覆盖方法明确标识 | 静态检查待接入；当前人审 |
| JAVA-03 | 不吞掉异常；不能把失败伪装成成功或无记录的空结果 | 测试和人审 |
| JAVA-04 | 资源有明确生命周期；异常路径也必须释放 | 静态检查待接入；集成测试和人审 |
| JAVA-05 | 自定义线程池明确队列、拒绝、超时、关闭策略；并发状态按契约同步 | 并发测试与人审；不机械禁止所有框架管理线程池 |
| JAVA-06 | 金额 / 精确小数按业务定义精度与舍入，避免二进制浮点直接代表金额 | 单元 / 边界测试；具体类型由领域契约确定 |
| JAVA-07 | equals / hashCode 一致；集合元素修改、空值和顺序语义明确 | 静态检查待接入；单元测试 |
| JAVA-08 | 参数验证包含业务合法性；区分缺失、空字符串和空集合 | 正常与非法输入测试 |
| JAVA-09 | 不共享非线程安全的可变格式化器等对象；时间带时区 / 精度契约 | 并发和时间边界测试 |
| JAVA-10 | 配置、阈值、业务规则可管理；业务可变策略不散落硬编码 | 需求和架构评审；并非所有常量都必须进数据库 |
| JAVA-11 | 接口返回的 DTO 与数据库对象按边界隔离；不泄露内部字段 | 契约 / 序列化测试 |
| JAVA-12 | 新依赖有必要性、固定版本、来源和升级方式 | 构建 / 依赖检查待接入 |

## 数据、权限与日志

- SQL 使用参数绑定；动态表名 / 排序字段等不可绑定部分使用明确白名单。
- 事务边界围绕业务原子性；避免长事务包住不确定的远端调用。
- 查询有适用的分页 / 上限；验证代表性数据量下的索引与访问路径。
- 业务决定幂等、唯一约束和并发更新策略；多次提交不能产生未定义副作用。
- 授权在服务端执行，租户身份来自可信上下文；拒绝路径不能泄露其他租户信息。
- 日志具有追踪标识和必要事件信息；不记录令牌、密码、完整敏感客户文本。
- 新增缓存需要定义失效、并发、数据一致性及回源策略。

这些规则按业务与部署环境判断，不能用风格检查替代。

## Web / TypeScript / JavaScript

采用本项目已有框架与工具，不为了符合外部指南更换工具链。先固定 formatter 和 lint 版本，每种文件只用一个格式器。边界对象有类型或运行时 schema；外部响应未经验证不直接视为可信类型。用户流程覆盖成功、失败、空状态、加载、权限、重复点击及可访问性要求。API 契约变化和前端行为一起评审。

Prettier / ESLint 可作为后续实施工具，但本包没有 Node 应用，也没有宣称这两个工具已启用或完全等同 Google 多语言指南。

## Python / Shell

Python 外部输入明确验证，数据处理保留单位、时区和缺失语义；通过项目测试与已选 lint / formatter。Shell 使用安全引用、清晰失败码和可重试策略；不可把用户输入拼进任意 shell 执行。纯本地治理脚本使用 Python 标准库，支持 Python 3.10+。

## 规则变更

规则增加或调整必须说明问题、影响、自动检查能力和迁移范围。全仓格式迁移单独 PR；不要让多个 Agent 各自挑一个外部风格。业务验收预期来自 spec，编码规范不能代替需求。
