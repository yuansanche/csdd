# 外部规范、优先级与冲突

规则基线：1.0.0。核对日期：2026-10-13。

## 规范的位置

宪章规定采用、冲突裁决、验证和变更流程。此文件规定外部来源和适用范围。[编码规范](coding-standards.md) 是 Agent 与人员实际执行的本地规则集。格式器 / 静态规则配置是可执行实现；发现它和文档不一致时必须处理，不能认为“工具说了算”。

## 权威顺序

1. 项目宪章的稳定原则。
2. 本项目经批准的架构、ADR、编码规则；业务行为由经批准的功能规格和契约具体规定。
3. 本项目明确采纳的外部规则。
4. 外部指南的其余建议。

同层文档出现冲突时暂停受影响部分，记录冲突并由负责该规则的人裁决。功能文档不能随意覆盖跨项目原则；例外应独立记录。现有系统接入时先记录现有约定，避免一次性全仓重排。

## 外部来源

| 来源 | 基线与适用方式 |
|---|---|
| [阿里巴巴 P3C 官方仓库](https://github.com/alibaba/p3c) | 仓库 README 指向黄山版，发布日期 2022-02-03。本项目筛选工程 / 业务风险规则；不把 P3C 检查通过等同于手册全覆盖 |

| [Google 官方多语言入口](https://google.github.io/styleguide/) | Web / Python / Shell 组件按语言选择相关规则；不把 Java 规则套用到其他语言 |
| [Spec Kit 官方仓库](https://github.com/github/spec-kit) | 本包实际 CLI 固定为 1.1.3；使用项目 override，保留官方初始化资产 |

外部网页没有被保存为不可变快照，不能声称已经锁定其完整内容。锁定的是本项目采纳规则和工具版本；升级规则必须差异评审。若后续需要手册全文离线分发，另行核对来源与许可，不直接复制整个网页。

## 已裁决的冲突

| 项目 | 本项目选择 | 执行方式 |
|---|---|---|
| Java 缩进 | Google 默认：2 空格 | 后续 google-java-format 默认模式；不启用 AOSP 的 4 空格模式 |
| Java 行宽 | Google 通常 100 列，保留其适用例外 | 格式器；不使用阿里巴巴排版器再次改写 |
| Java 大括号 / 换行 / import 排序 | 统一 Google Java 排版 | 单一格式器；不并行配置矛盾的 Checkstyle 排版规则 |
| 星号 import | 禁止 | 静态检查或人审；格式器不代表全覆盖 |
| 字段、参数、方法 | lowerCamelCase；类型 UpperCamelCase；常量 UPPER_SNAKE_CASE | 静态规则与评审；按语义命名 |
| Java boolean 字段 | 本项目使用 `enabled` 等字段名，方法可用 `isEnabled()`；序列化契约单独定义 | 这是项目裁决，面向框架兼容，不把它描述成所有语言共同规则 |
| 类 / 接口命名后缀 | 默认语义命名，不强制给所有接口实现增加 Impl | 本项目选择；外部系统生成类型按契约保留 |
| 现代 Java / 框架实践 | 按选定 JDK、框架和 ADR | 不机械禁止所有 Optional / record / lambda，也不盲目启用旧工具全套规则 |
| 旧项目已有排版 | 接入阶段保持现状，新增模块按确定的单一模式执行 | 全仓迁移单独 PR，避免业务变更夹杂重排 |

## 自动化覆盖声明

P3C 有规则实现和 IDE 插件，但并不覆盖整个手册。采用它之前核对 PMD、JDK、插件与项目版本兼容；关闭和本项目裁决冲突的规则，并记录关闭原因。Google 格式器只负责它覆盖的格式，不证明权限、事务、并发、架构或业务正确。

规则状态仅允许：`自动已接入`、`人工执行`、`待接入`、`不适用且有理由`。当前本包的 Java 业务工具均为待接入，治理结构检查已经可运行。
